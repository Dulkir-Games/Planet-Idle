# Upgrades

### Incoming mass (accretion)

| Tier | Object   |
|------|----------|
| 1    | Dust     |
| 2    | Pebble   |
| 3    | Rocket   |
| 4    | Boulder  |
| 5    | Asteroid |

Each tier is its own upgrade line: unlock the object type, then buy levels for more spawns.

### Gravity

Single upgrade, slow-growing multiplier (+pull strength and/or capture radius per level).
